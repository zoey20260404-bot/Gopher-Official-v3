# feat004：问题与解决记录

## 记录约定

开发和验证过程中发现的代表性问题、原因、修复与防回归措施记录于此。

## 2026-09-19：分支创建受到工作区沙箱限制

- 现象：首次执行 `git switch -c feature/zoey/feat004` 时无法创建 `.git/refs` lock 文件；
- 原因：当前工具会话默认仅允许读取 `.git`；
- 解决：在用户已明确授权开发的范围内，以受控权限仅重试分支创建；
- 防回归：遇到 Git 元数据写入失败时不改用文件系统绕过，保持 Git 操作原子性。

## 2026-09-19：数据库测试无法访问全局 uv cache

- 现象：设置本地测试数据库环境变量后，沙箱内的 `uv run` 无法初始化 `E:\python\cache`；
- 原因：uv cache 位于项目工作区外，当前受限文件系统不允许访问；
- 解决：仅对已确认的本地测试命令授予受控权限，未改变 cache 位置或项目配置；
- 防回归：不在仓库内创建临时依赖 cache，避免污染工作区和提交内容。
